# FAKE-NEWS-DETECTION
## Dataset

The datasets used in this project are stored in Google Drive because of their large file size.

### Download Datasets

- [Download Fake.csv](https://drive.google.com/file/d/17iCPehEefW3fawl0i24Gs6rWrx6UUf15/view?usp=sharing)
- [Download True.csv](https://drive.google.com/file/d/1MGGYa2e-jq9T6l7V5hlVpa7JP3JpmX-c/view?usp=sharing)

### Dataset Description

- Fake.csv - Contains fake news articles.
- True.csv - Contains real news articles.

Download both datasets and place them inside the project folder before running the code.
